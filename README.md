# Hebrew-Verb-Json-Generator
Data Entry assistant for Hebrew Verbs

Desktop app for entering and storing Hebrew verb conjugations and binyanim.

Features:
- Present / past / future forms
- JSON storage
- RTL Hebrew interface
- Linux + Windows executables

Built with Python + PyQt6.
